### Theme Toggle — Evidence

**Feature:** Switch between light and dark themes.

**Test path:** Open CampusVibes → Click the theme toggle → Observe the interface in each theme.

**Expected result:** The interface changes between light and dark themes, and the text and controls remain readable.

**Actual result:** **Actual result:** Successful. The theme toggle switched the CampusVibes interface between light mode and dark mode. The interface colors changed as expected, and the text and controls remained readable in both themes.
