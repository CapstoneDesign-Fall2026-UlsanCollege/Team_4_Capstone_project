
# Tech Stack Comparison

**Team:** team 4
**Week:** 3

Compare two possible stacks. Do not research everything. Prefer boring and buildable.

## Stack A

* **Stack name:** React + Firebase
* **What can we build with this?**
  We can build an interactive website with reusable components, user interfaces, Firebase database, authentication, and real-time data features.
* **What does the team already know?**
  The team knows basic HTML, CSS, JavaScript, and Firebase concepts.
* **What must we learn?**
  We need to learn React components, props, state management, React project structure, and how to connect React with Firebase.
* **How can we demo it by midterm?**
  We can create the main pages, navigation, basic reusable components, Firebase connection, and one or two main features of the project.
* **What could go wrong?**
  The team may need some time to learn React, and incorrect state management or Firebase configuration could cause development problems.
* **Simplest first screen or feature:**
  A homepage with navigation and a basic Firebase-connected feature.

## Stack B

* **Stack name:** HTML/CSS/JavaScript + Firebase
* **What can we build with this?**
  We can build a functional website using standard HTML, CSS, and JavaScript, with Firebase for storing and managing data.
* **What does the team already know?**
  The team already has basic knowledge of HTML, CSS, JavaScript, and Firebase.
* **What must we learn?**
  We need to learn how to organize a larger JavaScript project and connect different pages and features with Firebase.
* **How can we demo it by midterm?**
  We can quickly create the main webpage, navigation, forms, and basic Firebase features.
* **What could go wrong?**
  As the project becomes larger, the code may become harder to organize and maintain. Reusing the same components across different pages can also be more difficult.
* **Simplest first screen or feature:**
  A basic HTML homepage with CSS styling and a JavaScript/Firebase feature.

## Decision

We choose:

> **React + Firebase**

Because:

> **React is more suitable for managing our project as it grows. Its reusable components can help us organize the code and develop features more efficiently. Firebase can handle the backend services such as database and authentication. Although we need to learn React, we believe the stack is manageable and suitable for our project.**

## Instructor approval / notes

* **Team discussed and agreed on React + Firebase.**
* **React will be used for the frontend and Firebase for backend services.**
* **We will focus on building a simple working prototype first.**
