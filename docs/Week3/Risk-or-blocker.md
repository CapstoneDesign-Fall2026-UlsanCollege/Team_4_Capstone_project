## What is the risk or blocker?
We may have difficulty getting reliable and up-to-date event information from the university website or other event sources.

## Why does it matter?
If event data is missing or outdated, students may see incorrect information in the CampusVibe app. This could affect the main Events feature

## What have we tried?
We checked the available university event pages and considered using manually added event data for the MVP.

## What decision or help do we need?
We need to decide whether to use a simple manual event database for the MVP or connect the app to an external event data source.
