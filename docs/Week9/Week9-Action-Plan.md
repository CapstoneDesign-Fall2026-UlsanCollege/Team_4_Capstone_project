We will verify that:

- Event information is displayed correctly.

**Success measurement:** All agreed Firestore event-loading test cases pass, with screenshots and actual results recorded in GitHub Issues.

By the end of Week 9, the team should have a cleaner backlog, a tested backup demo setup, and a clear quality improvement target for the final MVP.
