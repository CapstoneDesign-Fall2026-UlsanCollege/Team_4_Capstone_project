# Final Demo Script

**Team:** 4  
**Project:** CampusVibes  
**Week:** 14–16

## Opening

- **Project name:** CampusVibes
- **Target users:** University students who want to discover campus events, clubs, and activities.
- **Problem solved:** Students may find it difficult to discover campus events and activities because information is spread across different platforms. CampusVibes provides one place to explore and discover campus activities.
- **Final project state:** A React and Firebase-based campus event discovery application. The final demonstration will show the verified features, explain the current limitations, and present the completed project documentation and testing evidence.

## Demo path

1. **Landing Page and Login**
   - Open the deployed CampusVibes website.
   - Show the landing page.
   - Log in using a verified email and password account.

2. **Dashboard**
   - Show the dashboard after login.
   - Briefly explain the main navigation and available sections.

3. **Discover / Events**
   - Open the Discover or Events page.
   - Demonstrate event search and filters.
   - Show the available sample events.

4. **Event Details**
   - Select an event.
   - Show its basic information and details.
   - Explain how students can explore events through the application.

**Supporting features:** If time permits and their behavior has been verified, briefly show Saved Events, Profile, Assistant, Suggestions, social features, and the light/dark theme toggle.

## Fallback plan

If the live demo fails, we will show:

- Screenshots of the main application pages, including the Landing Page, Dashboard, Events page, and Event Details.
- The deployed website, available testing screenshots, and GitHub evidence to explain the implemented features.

If the deployed website is unavailable, we will use a local project setup if it has been tested successfully before the presentation.
