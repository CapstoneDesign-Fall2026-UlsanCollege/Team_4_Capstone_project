## Done means

- [ ] The visible result or tangible change is clear.
- [ ] A teammate can reach the work through the linked Issue, branch, preview, or steps.
- [ ] Someone other than the author checked it.
- [ ] The expected result and actual result are written down.
- [ ] At least one useful evidence link is attached.
